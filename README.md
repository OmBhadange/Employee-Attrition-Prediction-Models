# Employee Attrition Prediction Models

## Project Overview
This project uses machine learning to predict employee attrition using the IBM HR Analytics Employee Attrition dataset.

## Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost
- Tuned Random Forest

## Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- XGBoost
- Google Colab

## Model Performance

| Model | Accuracy | F1-score |
|---|---:|---:|
| XGBoost | 87.76% | 45.45% |
| Logistic Regression | 86.05% | 43.84% |
| Decision Tree | 77.89% | 34.34% |
| Tuned Random Forest | 85.03% | 24.14% |
| Random Forest | 84.69% | 23.73% |

## Evaluation Metrics
Accuracy, Precision, Recall, F1-score, and ROC-AUC.

## Project Files
- `Employee_Attrition_Prediction_Models.ipynb` — Complete machine learning notebook.
- `Employee_Attrition_Models.zip` — Saved model and preprocessing files.

## Conclusion
XGBoost achieved the highest test accuracy and F1-score among the evaluated models. Further improvements in recall are needed to identify more employees at risk of leaving.
